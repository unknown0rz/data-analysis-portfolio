# Data Analysis Portfolio

SQL / BigQueryを使ったデータ分析のポートフォリオです。
公開されている実データをもとに、自分で問いを立て、
「問い → 集計 → 結果の解釈 → 提案」までを一通り行っています。

## Skills

- SQL(BigQuery):JOIN / CTE(WITH) / CASE WHEN / 条件付き集計 / ウィンドウ関数(LAG など)
- Excel:データの読み込み、グラフ作成
- Git / GitHub
